Чек лист проверки корзины

Проверка отсутствия товара в корзине
1. авторизоваться;
2. не добавлять товар в корзину;
3. перейти в корзину;
4. проверить отображение страницы корзины;
5. проверить отсутствие товара в корзине.

Проверка наличия в корзине товара, определенного количества.
1. авторизоваться;
2. проверить отображение страницы с товарами;
3. добавить в корзину 2 товара;
4. перейти в корзину;
5. проверить отображение страницы корзины;
6. проверить наличие в корзине 2 товаров.

Проверка уделения товара из корзины.
1. авторизоваться;
2. проверить отображение страницы с товарами;
3. добавить в корзину 2 товара;
4. перейти в корзину;
5. проверить отображение страницы корзины;
6. удалить из корзины 2 товара; 
7. проверить отсутствие товара в корзине.

Проверка работы кнопки ContinueShopping
1. авторизоваться;
2. не добавлять товар в корзину;
3. перейти в корзину;
4. проверить отображение страницы корзины;
5. нажать кнопку ContinueShopping;
6. проверить отображение страницы с товарами.

Проверка работы кнопки Checkout
1. авторизоваться;
2. не добавлять товар в корзину;
3. перейти в корзину;
4. проверить отображение страницы корзины;
5. нажать кнопку Checkout;
6. проверить отображение страницы для оформления покупки - 1 шаг.

Чек лист проверки Checkout
Предусловие: авторизоваться, добавить товар в корзину, перейти в корзину, нажать кнопку Checkout.

Проверка кнопки корзина
1. нажать кнопку корзина;
2. проверить отображение страницы корзины.

Проверка кнопки Cancel
1. нажать кнопку Cancel;
2. проверить отображение страницы корзины.

Проверка формы оформления покупки 1 шаг и кнопки Continue (негативный)
1. не заполнять поля формы для оформления покупки;
2. нажать кнопку Continue;
3. проверить отображение ошибки;
4. заполнить поле First Name;
5. нажать кнопку Continue;
6. проверить отображение ошибки;
7. очистить поле First Name, заполнить поле Last Name;
8. нажать кнопку Continue;
9. проверить отображение ошибки;
10. очистить поле Last Name, заполнить поле Zip/Postal Code;
11. нажать кнопку Continue; 
12. проверить отображение ошибки;------------
13. заполнить полк First Name, Last Name;
14. нажать кнопку Continue; 
15. проверить отображение ошибки;
16. очистить поле First Name, заполнить поле Last Name, Zip/Postal Code;
17. нажать кнопку Continue;
18. проверить отображение ошибки;
19. очистить поле Last Name, заполнить поле First Name, Zip/Postal Code;
20. нажать кнопку Continue; 
21. проверить отображение ошибки.

Проверка формы оформления покупки 1 шаг и кнопки Continue (позитивный)
1. заполнить все поля формы для оформления покупки;
2. нажать кнопку Continue;
3. проверить отображение страницы для оформления покупки - 2 шаг.

Проверка формы оформления покупки 2 шаг (негативный)
1. заполнить все поля формы для оформления покупки;
2. нажать кнопку Continue;
3. проверить отображение страницы для оформления покупки - 2 шаг.
4. нажать кнопку Cancel;
5. проверить что не отображается страница для оформления покупки - 2 шаг.

Проверка формы оформления покупки 2 шаг (позитивный)
1. заполнить все поля формы для оформления покупки;
2. нажать кнопку Continue;
3. проверить отображение страницы для оформления покупки - 2 шаг.
4. нажать кнопку Finish;
5. проверить отображение страницы завершения покупки.
